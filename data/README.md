# 📊 PVR Movie Booking Dataset

## Overview

The `PVR_Movie_Booking_Dataset.xlsx` file contains structured data for the PVR Movie Booking Analytics project. It is intended for exploring movie bookings, ticket sales, revenue, customer preferences, cinema performance, and showtime trends using data analytics and visualization tools.

## Dataset File

- **File Name:** `PVR_Movie_Booking_Dataset.xlsx`
- **File Format:** Microsoft Excel (`.xlsx`)
- **Worksheets:** 10

## Dataset Structure

| Worksheet | Description |
|---|---|
| `Bookings` | Booking records, ticket prices, discounts, and booking status |
| `Movies` | Movie titles, genres, languages, and release information |
| `Customers` | Customer information, locations, and membership details |
| `Cinemas` | Cinema locations, facilities, and cinema details |
| `Screens` | Screen capacity, screen formats, and audio features |
| `Showtimes` | Movie schedules, ticket prices, and occupancy information |
| `Payments` | Payment methods, transaction amounts, and payment status |
| `Tickets` | Ticket identifiers, seat numbers, and booking references |
| `Data_Dictionary` | Definitions of dataset tables and columns |
| `Read_Me` | Dataset instructions and general information |

## Key Analysis Areas

- Movie booking and ticket sales analysis
- Revenue and refund analysis
- Movie and genre performance
- Booking trends over time
- Customer and membership analysis
- Cinema and city performance comparison
- Payment method analysis
- Showtime occupancy analysis
